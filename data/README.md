# Data dizini

Bu dizindeki veri dosyaları yerel kullanım içindir ve GitHub'a yüklenmez.

- `raw/`: Değiştirilmemiş kaynak veri
- `interim/`: Ara işlem çıktıları
- `processed/`: Modellemeye hazır veri
- `external/`: Sonradan eklenebilecek harici veri kaynakları

PaySim CSV dosyasının beklenen yolu:

```text
data/raw/PS_20174392719_1491204439457_log.csv
```
