# FraudShield ML v1.0.0 Release Notes

Welcome to the v1.0.0 release of FraudShield ML! This release represents the culmination of 11 distinct development phases to transition from raw dataset exploration into a fully containerized, explainable, and observable MLOps system.

## Key Highlights

- **Data Validation & Leakage-Safe Splitting**: Implemented strict temporal validation to prevent future-data leakage, dropping naive randomized splits.
- **Simulation-Artifact Audit & Model Selection**: Audited tree-based models (LightGBM) achieving 1.0 PR-AUC. Discovered they were exploiting deterministic balance-error artifacts generated by the synthetic PaySim dataset. Rejected this model in favor of a strictly point-in-time-safe, generalizable PyTorch MLP model.
- **Explainable AI (XAI)**: Integrated `captum` (Integrated Gradients) to attribute model logits back to raw input features, assigning human-readable Reason Codes to every prediction.
- **Portable Inference Bundle**: Extracted legacy `scikit-learn` preprocessors and isotonic calibrators into pure NumPy arrays and JSON parameters. This safely decouples inference from `joblib` unpickling, enabling cross-version compatibility and improved security.
- **Microservices Deployment**: 
  - **FastAPI**: Asynchronous API serving models with strict Pydantic schema validation.
  - **PostgreSQL**: Immutable case management data store tracking analyst events.
  - **Streamlit**: Fully functional analyst dashboard to triage cases and review explainability metrics.
- **Docker & Observability**: Complete `docker compose` orchestrator enclosing the API, Dashboard, Database, Prometheus, and Grafana.

## Known Limitations
- The underlying PaySim dataset is entirely synthetic; **no real banking deployment was performed**.
- The evaluation holdout set was previously accessed during Phase 3 baselining and is not perfectly pristine.
- The calibrated output represents an empirical probability estimate within the synthetic environment, not an absolute real-world probability.
- The system is a **production-oriented portfolio and demonstration system**, not a banking-production-ready enterprise solution.
- The compiled inference bundle is strictly designated as **Local-only pending licensing review** until explicit redistribution rights are confirmed.
