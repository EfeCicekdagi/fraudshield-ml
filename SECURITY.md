# Security Policy

## Supported Versions

Currently, the only supported version is:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.0   | :white_check_mark: |
| < 1.0.0 | :x:                |

*Note: This is a demonstration and portfolio project. We do not provide continuous security monitoring or enterprise SLA guarantees.*

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please follow these guidelines:

1. **Do not open a public issue.** Public issues exposing vulnerabilities put other users at risk.
2. Email the repository owner (Efe Çiçekdağı) privately to disclose the issue.
3. Allow a reasonable amount of time for a response and patch before public disclosure.

## General Warning

- **Do not submit secrets or real financial data in public issues.**
- The default configuration uses unencrypted HTTP and basic API keys designed for local demonstration purposes. It is your responsibility to secure this deployment if you intend to run it on a public network.
